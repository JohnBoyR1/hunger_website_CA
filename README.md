# Zero Hunger Project

A collaborative first-year web development project created by a team of three students as part of our studies at the National College of Ireland.

The aim of the project was to design and develop an interactive charity-style website focused on raising awareness of food shortages, food poverty and community support.

The website encourages users to learn about food donation, volunteer in community kitchens, participate in donation drives and explore ways they can help tackle hunger within their communities.

## Project Overview

The Zero Hunger Project was developed as a three-person group project.

The website contains several interconnected sections, including:

- Home page
- Community kitchen and volunteering section
- Kitchen volunteer signup
- Contact section
- Food bank information
- Donation drive
- Quiz and Q&A
- Interactive forms
- Images and video content

The project gave our team practical experience designing and developing a multi-page website while dividing development responsibilities between team members and combining our work into a single application.

## Kitchen Section

The Kitchen section was designed around the idea of community kitchens where volunteers can help prepare and serve meals.

The page uses video and interactive elements to make the volunteering section more engaging.

Features include:

- Video carousel displaying community kitchen activities
- Volunteer call-to-action buttons
- Interactive team-leader information
- Bootstrap modal windows
- Dynamic modal content controlled with JavaScript
- Video content within team-member profiles
- Navigation to the volunteer registration page

JavaScript is used to dynamically change the information and video displayed within the modal depending on which kitchen team member the user selects.

## Volunteer Signup

I developed the Kitchen Volunteer Signup page to demonstrate how a volunteer registration system could work.

The form collects information including:

- First name
- Last name
- Gender selection
- Address
- Town or city
- County
- Email address
- Password
- Password confirmation

JavaScript validation is used to check the information entered by the user before the form is accepted.

Validation includes:

- Required first and last names
- Required address
- Town/city selection
- County selection
- Gender selection
- Email address validation
- Required password
- Password confirmation
- Checking that both passwords match

As this was a front-end academic project without a backend database, the registration information is not permanently stored.

The signup functionality was designed to demonstrate how validated information could later be passed to a backend application.

## Running the Project

No installation or backend server is required.

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

Alternatively, the project can be opened in Visual Studio Code and run using a local development server such as Live Server.
